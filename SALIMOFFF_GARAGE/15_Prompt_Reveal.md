# 15 — Prompt Reveal (yeni mini seriya, 23:00 UTC slotu)

30.11-dən başlayaraq hər yayım günündə 3-cü Short: **həmin günün əsas epizodunun arxasındakı prompt**. Yeni generasiya lazım deyil: əsas epizodun klipləri istifadə olunur.

Niyə vacibdir:
1. YouTube-un "inauthentic content" qaydasına qarşı ən güclü sübutdur: insan işi, proses və izah göstərilir.
2. Səni **AI mütəxəssisi** kimi tanıdır. Bu, B2B müştərilər (avtosalonlar) və gələcək kurs/xidmət satışı üçün vitrindir.
3. Bu Short-lar Avropa/Amerika vaxtı ilə axşam (18:00 ET) çıxır. Həmin saatda AI ilə maraqlanan auditoriya aktivdir.

## Format (20–25 san, 9:16)
| Saniyə | Kadr | Səs |
|---|---|---|
| 0–2 | Ekran mətni: "This prompt made this car" + nəticənin ən güclü kadrı | Beat start |
| 2–12 | Ekranın üst yarısı: prompt mətni typewriter effekti ilə yazılır (JetBrains Mono, ağ, qara fon). Alt yarısı: həmin hissənin klipi | Klaviatura ASMR + beat |
| 12–20 | Açar sözlər yaşıl rənglə vurğulanır (məs. `IMAX 85mm`, `liquid wave`, `continuity`) və nəticədə uyğun an göstərilir | Beat |
| 20–23 | "Full prompt in the comments" + watermark | Bass hit |

CapCut: Text → Animation → **Typewriter**. Promptun tamamı ekrana sığmırsa, yalnız ilk 2–3 cümləni göstər.
