# Dəmir Cəbhə

Brauzerdə işləyən 3D müharibə oyunu (first-person shooter). Bir faylda (`index.html`), Three.js ilə yazılıb. Bütün qrafika və səslər kodla yaradılır, xarici şəkil və ya səs faylı yoxdur.

## Necə oynamaq

`index.html` faylını brauzerdə aç (Chrome, Edge, Firefox, Safari). İnternet lazımdır, çünki Three.js CDN-dən yüklənir.

Dağılmış kəndin mərkəzindəki mövqeni qoru. Düşmən dalğalarla gəlir, hər 5-ci dalğada tank hücuma keçir.

| Düymə | Əməliyyat |
|---|---|
| WASD | Hərəkət |
| Shift | Qaçış |
| Space | Tullanma |
| C | Çöməlmə |
| Sol klik | Atəş |
| Sağ klik (və ya F) | Nişan / optika |
| R | Doldurma |
| G | Qumbara |
| 1–4, təkər | Silah seçimi |
| Q | Əvvəlki silah |
| E | Sursat qutusu (mərkəzdə) |
| M | Səsi söndür |
| Esc / P | Fasilə |

Telefonda toxunma idarəetməsi avtomatik açılır (sol joystik, sağ tərəfdə baxış və düymələr).

## İçindəkilər

- Prosedur relyef, 13 dağılmış bina, səngərlər, yanan texnika qalıqları, meşələr, küləkdə yellənən ot
- 4 silah: KR-27 avtomat, VX-12 ov tüfəngi, ŞAHİN-50 snayper (optika ilə), RQ-7 qumbaraatan
- Düşmən süni intellekti: patrul, görmə xətti, cinahdan keçmə, örtükdə çöməlmə, seriya atəşi
- Tank (boss): fırlanan qüllə, mərmi, pulemyot
- Partlayan çəlləklər, zəncirvari partlayışlar, qumbaralar
- Başdan vuruş, xal, rekord, dəqiqlik statistikası
- Radar, zərər istiqaməti göstəricisi, hit-marker
- Sintez olunmuş səslər (atəş, partlayış, addımlar, uzaqdan döyüş fonu)
- 3 çətinlik və 3 qrafika səviyyəsi
